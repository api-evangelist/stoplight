# Stoplight

> Stoplight is a collaborative, design-first API platform: a visual OpenAPI editor,
> hosted interactive documentation, automatic Prism-powered mock servers, and API
> style guides and governance through Spectral. Acquired by SmartBear in 2023 and now
> positioned inside SmartBear's API Hub alongside SwaggerHub. Generated by API
> Evangelist on 2026-08-27 — Stoplight serves no /llms.txt of its own (404 on
> stoplight.io and docs.stoplight.io, probed 2026-08-27).

Important: Stoplight publishes no OpenAPI for its CURRENT platform API. The only
machine-readable contract it has ever published is for the legacy v1 (Classic) API,
five operations, mirrored below. Everything else on this page is documentation.

## APIs

- [Stoplight Platform](https://stoplight.io): SaaS design-first API design, documentation, mocking and governance. OpenAPI 3.1/3.0/2.0, Arazzo 1.0, AsyncAPI 2.x. Git integrations for GitHub, GitLab, Bitbucket and Azure DevOps.
- [Stoplight v1 (Classic) Platform API](https://api.stoplight.io/v1): Legacy. Export, import, publish and unpublish an API description version. Authorization header API key.
- [Prism](https://stoplight.io/open-source/prism): Open-source HTTP mock and validation-proxy server for OpenAPI 2/3 and Postman Collections.
- [Spectral](https://stoplight.io/open-source/spectral): Open-source JSON/YAML linter for API style guides and governance.
- [Elements](https://stoplight.io/open-source/elements): Open-source React / Web Component library for interactive API reference documentation.
- [Stoplight CLI](https://docs.stoplight.io/docs/platform/f76c84240244f-publish-with-the-stoplight-cli): Publish local project content into a Stoplight workspace from CI.

## Not available

- No MCP server. SmartBear's official MCP server (@smartbear/mcp) covers Swagger/API Hub, BugSnag, Zephyr and others — it exposes no Stoplight tools.
- No A2A agent card on any host (/.well-known/agent-card.json and /.well-known/agent.json both 404).
- No AsyncAPI or webhook surface for the Stoplight platform.
- No GraphQL, gRPC/Protobuf or SOAP/WSDL contract.
- No OAuth 2.0 or OpenID Connect for API access; no published OAuth scopes.
- No published rate limits, no security.txt, no public roadmap, no platform changelog.
