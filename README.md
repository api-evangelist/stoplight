# Stoplight (stoplight)
Stoplight is a collaborative, design-first API platform that provides a visual editor for OpenAPI specifications, interactive hosted documentation, automatic mock servers, API style guides and governance, and open-source tools including Prism, Spectral, and Elements. Acquired by SmartBear in 2023, Stoplight enables teams to design, document, and govern APIs at scale.

### Stoplight Platform
Stoplight Platform is a collaborative API design and documentation management tool that provides a visual editor for OpenAPI specifications, interactive hosted documentation, automatic mock servers, API style guides, governance features, and multi-branch Git integration. It enables teams to design, document, mock, and govern APIs using a design-first approach with no specialized knowledge required.

### Stoplight Prism
Prism is an open-source HTTP mock and proxy server that accelerates API development. It turns any OpenAPI v2 or v3 and Postman Collection file into a realistic API server with mocking, transformations, and validations, enabling frontend and backend teams to develop in parallel with hosted mock servers powered by API descriptions.

**Human URL:** [https://stoplight.io/open-source/prism](https://stoplight.io/open-source/prism)

### Stoplight Spectral
Spectral is an open-source JSON and YAML linter for creating automated API style guides. It provides baked-in support for OpenAPI v3.1, v3.0, and v2.0, Arazzo v1.0, and AsyncAPI v2.x, enabling teams to automate validation and enforce consistent API design standards across their organization.

**Human URL:** [https://stoplight.io/open-source/spectral](https://stoplight.io/open-source/spectral)

### Stoplight Elements
Elements is an open-source tool for building beautiful, interactive API documentation with embeddable React or Web Components, powered by OpenAPI and Markdown. It offers highly customizable and interactive embeddable web documentation to enhance user experience and developer engagement.

### Stoplight Studio
Stoplight Studio is the modern editor for API design and technical writing. It provides a visual, form-based editor for creating and editing OpenAPI v2 and v3 specifications, with full validation, mocking, and modeling support. Studio includes a built-in Markdown editor, image manager, and the ability to publish documentation to the Stoplight documentation platform.

**Human URL:** [https://stoplight.io/api-design](https://stoplight.io/api-design)
